# AjimaOps Portfolio

## Overview

AjimaOps is my personal portfolio website designed to showcase my technical skills, projects, engineering mindset, and ongoing journey as a software engineer.

The portfolio serves as a central hub where recruiters, engineers, and potential collaborators can learn about my background, technical expertise, and interests across software development, backend engineering, Linux systems, networking, cloud-native technologies, and infrastructure.

Built with a modern React-based architecture, the application emphasizes performance, responsiveness, maintainability, and clean user experience.

---

## Purpose

This project was created to:

- Present my professional profile and technical background.
- Demonstrate frontend engineering skills using modern web technologies.
- Showcase my software engineering journey and learning path.
- Provide a central location for future project demonstrations.
- Serve as a platform for networking and professional opportunities.

---

## Features

Responsive User Interface

The application is fully responsive and optimized for desktop, tablet, and mobile devices.

Modern Single Page Application

Built using React Router for client-side navigation, providing a seamless browsing experience without full page reloads.

Interactive Animations

Utilizes Framer Motion to create smooth transitions and enhance user engagement while maintaining performance.

Skills Showcase

Presents technical competencies across multiple domains, including:

- Frontend Engineering
- Backend & API Development
- DevOps & Infrastructure
- Networking & Security
- Computer Science Fundamentals
- Developer Tools & Workflow

Contact System

Integrated with Formspree to allow visitors and recruiters to send messages directly through the website.

Professional Branding

The portfolio reflects my interests in:

- Linux Systems
- Networking
- Cloud Infrastructure
- Backend Engineering
- Distributed Systems
- Software Architecture
- DevOps Practices

## Running Locally

Clone the repository:
```
git clone https://github.com/your-username/ajimaops.git
```
Navigate into the project directory:
```
cd ajimaops
```
Install dependencies:
```
npm install
```
Start the development server:
```
npm run dev
```
Build for production:
```
npm run build
```
